# 케셰브 새 환경 재현 기록과 버전 기록 (22단계)

이 문서는 학생이 새로 작성한 문서입니다. 제공 파일(`README.md`, `package.json`, `docs/` 아래 기존 제공 문서, `src/`, `public/`)은 고치지 않았습니다.
이 기록은 **학생 진술**입니다. 서버나 심사 AI가 새 환경에서 실행했다는 뜻이 아니며, AI 원문 검토 결과를 실행 성공의 증명으로 쓰지 않습니다.

## 0. 표기 약속

| 표기 | 뜻 |
|---|---|
| 실제 화면 확인 | 새 폴더에서 앱을 켜고 브라우저 화면이나 PowerShell 출력으로 직접 본 것 |
| 예제 자료 | `-Demo`(예제 데이터) 모드에서 본 것. **실제 연결 재현이 아닙니다** |
| 코드만 읽음 | 소스 코드를 읽어 확인했지만 실행하지 않은 것 |
| 미확인(UNV) | 실행하지 않았거나 결과를 받지 못한 것 |

결과 칸은 「재현됨 / 재현 안 됨 / 연결 없음 / 확인 불가」 가운데 하나로 적고, 시험하지 않은 칸은 「미확인」으로 둡니다.

## 7. 이동 가능한 구성 점검

- 실행에 필요한 파일은 모두 Git에 있습니다. 새 폴더에서 `npm install` 없이 실행됐습니다. (실제 확인)
- 실행 명령은 상대 경로(`.\tools\start-alekov.ps1`)라서 폴더 위치에 묶이지 않습니다. `docs/STUDENT_RUNBOOK.md` 4-1의 절대 경로는 내 PC의 예시입니다.
- 폴더 위치 제한: Git 폴더를 사용자 폴더 바로 아래(`C:\Users\<이름>\<저장소>`)에 두면 실행 도구가 멈춥니다. `C:\Users\<이름>\<프로젝트 폴더>\on-client`처럼 한 단계 안에 둡니다. (실제 확인)
- 비밀값: 저장소·이 문서에 열쇠·토큰·비밀번호·인증서를 넣지 않았습니다.
